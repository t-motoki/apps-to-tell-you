# 要求定義書: 写真のテキスト変換機能

## 1. 機能概要

### What（何を実現するか）

写真の画像ファイルをテキスト説明に変換し、メッセージアプリで共有できるようにする

### Why（なぜ必要か）

写真を受信できないアプリを使用している相手にも、視覚的な情報を正確にテキストで伝えるため

### Intent（最優先の意図）

ユーザーが写真を選択してから、テキスト説明を取得するまでを3ステップ以内で完了できる

## 2. ユーザーストーリー

- **As a** メッセージアプリのユーザー
- **I want to** 写真の内容をテキストに変換する
- **So that** 写真を受信できない相手にも視覚的な情報を伝えられる

## 3. 機能要件

### 要件1: 画像選択機能

**説明**: ユーザーが端末のギャラリーまたはカメラから画像を選択できる

**受入基準（Acceptance Criteria）**:

```gherkin
Scenario: ギャラリーから画像を選択
  Given アプリが起動している
  When ユーザーが「ギャラリーから選択」ボタンをタップする
  Then 端末のギャラリーが開く
  And ユーザーが画像を選択できる
  And 選択した画像がアプリに表示される
```

```gherkin
Scenario: カメラで撮影
  Given アプリが起動している
  When ユーザーが「カメラで撮影」ボタンをタップする
  Then カメラが起動する
  And ユーザーが写真を撮影できる
  And 撮影した画像がアプリに表示される
```

```gherkin
Scenario: 画像選択のキャンセル
  Given ギャラリーまたはカメラが起動している
  When ユーザーがキャンセル操作を行う
  Then アプリのメイン画面に戻る
  And エラーメッセージは表示されない
```

### 要件2: 画像からテキストへの変換機能

**説明**: 選択された画像を解析し、内容を説明するテキストを生成する

**受入基準（Acceptance Criteria）**:

```gherkin
Scenario: 正常に変換が完了
  Given ユーザーが画像を選択している
  When ユーザーが「テキストに変換」ボタンをタップする
  Then 変換処理中のローディング表示がされる
  And 画像の内容を説明するテキストが生成される
  And 生成されたテキストが画面に表示される
```

```gherkin
Scenario: 変換処理の失敗
  Given ユーザーが画像を選択している
  When 画像変換APIがエラーを返す
  Then エラーメッセージが表示される
  And ユーザーに再試行のオプションが提示される
```

```gherkin
Scenario: ネットワークエラー
  Given ネットワーク接続がない状態
  When ユーザーが「テキストに変換」ボタンをタップする
  Then ネットワークエラーメッセージが表示される
  And ユーザーに接続確認を促すメッセージが表示される
```

### 要件3: テキスト表示・共有機能

**説明**: 変換されたテキストを表示し、他のアプリに共有できる

**受入基準（Acceptance Criteria）**:

```gherkin
Scenario: テキストのコピー
  Given 変換されたテキストが表示されている
  When ユーザーが「コピー」ボタンをタップする
  Then テキストがクリップボードにコピーされる
  And コピー完了の通知が表示される
```

```gherkin
Scenario: 他アプリへの共有
  Given 変換されたテキストが表示されている
  When ユーザーが「共有」ボタンをタップする
  Then OSのシェアシートが表示される
  And ユーザーが共有先アプリを選択できる
  And 選択したアプリにテキストが渡される
```

```gherkin
Scenario: テキストの編集
  Given 変換されたテキストが表示されている
  When ユーザーがテキストエリアをタップする
  Then テキストが編集可能になる
  And ユーザーが内容を修正できる
```

## 4. 非機能要件（NFR）

### 性能要件

- **レスポンスタイム**: 画像変換処理のp95 < 10秒
- **画像サイズ制限**: 最大10MB
- **対応画像形式**: JPEG, PNG, HEIC

### 可用性

- **SLA**: 変換API利用時は外部サービスに依存
- **オフライン対応**: オフライン時は適切なエラーメッセージを表示
- **リトライ**: 一時的なエラー時は自動リトライ（最大3回）

### セキュリティ

Constitution のセキュリティポリシーに準拠し、以下の要件を満たす：

- [ ] 画像データは変換処理後に端末内で削除（必要に応じて）
- [ ] 外部APIへの通信はHTTPS暗号化
- [ ] 画像データの送信時はユーザーの同意を得る
- [ ] APIキー等の機密情報は環境変数で管理

### 観測性

- **ログ**:
  - 画像変換リクエスト（成功/失敗）
  - エラー発生時の詳細情報
  - ユーザー操作のフロー
- **メトリクス**:
  - 変換成功率
  - 平均変換時間
  - エラー発生率
- **トレース**:
  - 画像選択から変換完了までの処理時間
  - API呼び出しのレスポンスタイム

## 5. スコープ

### 含む

- 端末のギャラリーから画像を選択する機能
- カメラで撮影した画像を使用する機能
- 画像をテキスト説明に変換する機能
- 生成されたテキストを表示する機能
- テキストをクリップボードにコピーする機能
- テキストを他アプリに共有する機能
- 変換前にテキストを編集する機能
- iOS/Android両プラットフォーム対応

### 含まない

- 複数画像の一括変換
- 変換履歴の保存機能
- オフラインでの画像変換（初期バージョンでは対応しない）
- 動画のテキスト変換
- 音声による説明の生成
- ユーザー認証機能
- テキストの多言語翻訳

## 6. I/O仕様

### React Native アプリケーション

**Input（画像選択）**:
```typescript
// ギャラリーまたはカメラから取得
{
  uri: string;           // 画像のローカルURI
  type: 'image/jpeg' | 'image/png' | 'image/heic';
  fileSize: number;      // バイト単位
  width: number;
  height: number;
}
```

**Input（画像変換APIリクエスト）**:
```typescript
{
  image: string;         // Base64エンコードされた画像データ
  format: string;        // 画像フォーマット
}
```

**Output（変換結果）**:
```typescript
{
  success: boolean;
  description: string;   // 画像の説明テキスト
  confidence?: number;   // 変換の信頼度（オプション）
}
```

**Error**:
```typescript
{
  error: {
    code: string;        // 'NETWORK_ERROR' | 'API_ERROR' | 'INVALID_IMAGE' | 'SIZE_EXCEEDED'
    message: string;     // ユーザー向けエラーメッセージ
    details?: string;    // 技術的な詳細（デバッグ用）
  }
}
```

## 7. 依存関係

### 外部サービス
- **画像認識API**: 画像をテキストに変換（例: OpenAI Vision API, Google Cloud Vision API等）
  - API選定は設計フェーズで決定

### React Nativeライブラリ
- **react-native-image-picker**: ギャラリー選択・カメラ撮影機能（v7.x以上）
- **@react-native-clipboard/clipboard**: クリップボード操作（v1.x以上）
- **react-native-share**: 共有機能（v10.x以上）

### 内部依存
- TypeScript (v5.x以上)
- React Native (v0.73以上を推奨)

## 8. Open Questions

1. 使用する画像認識APIの選定
   - OpenAI Vision API / Google Cloud Vision API / AWS Rekognition 等のどれを使用するか
   - コスト・精度・レスポンス時間を考慮して決定

2. 画像データの扱い
   - 変換処理後、元画像データをキャッシュするか
   - プライバシー保護の観点からの考慮事項

3. 変換テキストの詳細度
   - 簡潔な説明 vs 詳細な説明のどちらをデフォルトとするか
   - ユーザーが詳細度を選択できるようにするか

4. 多言語対応
   - 初期バージョンでは日本語のみか
   - UIの言語設定をどう扱うか

5. エラーハンドリングの詳細
   - リトライのロジック（間隔、回数）
   - ユーザーへのフィードバックの方法
