# 要求定義書: 写真のテキスト変換機能

**バージョン**: v1.1
**最終更新**: 2026-01-11
**ステータス**: レビュー完了

## 1. 機能概要

### What（何を実現するか）

写真の画像ファイルをAI画像認識により詳細なテキスト説明に変換し、メッセージアプリで共有できるようにする

### Why（なぜ必要か）

写真を受信できないメッセージアプリを使用している相手にも、視覚的な情報を正確かつ詳細にテキストで伝えるため

### Intent（最優先の意図）

ユーザーが直感的に操作でき、写真選択からテキスト説明の取得・共有までを3ステップ以内で完了できる優れたUXを提供する

## 2. ユーザーストーリー

- **As a** LINEなどのメッセージアプリのユーザー
- **I want to** 写真の内容を詳細なテキスト説明に変換する
- **So that** 写真を受信できないアプリを使っている相手にも、視覚的な情報を的確に伝えられる

## 3. 機能要件

## 4. 非機能要件（NFR）

### 性能要件

- **レスポンスタイム**:
  - 画像選択操作: p95 < 500ms（即座にフィードバック）
  - 画像変換処理（API呼び出し含む）: p95 < 10秒、p99 < 15秒
  - テキストコピー操作: p95 < 100ms
  - UI操作全般: p95 < 300ms（スムーズな体験）
  - アプリ起動時間: p95 < 2秒（コールドスタート）
- **画像サイズ制限**:
  - 最大ファイルサイズ: 10MB（10,485,760バイト）
  - 最小解像度: 100x100ピクセル
  - 最大解像度: 制限なし（ただし10MB以下）
- **対応画像形式**: JPEG, PNG, HEIC（iOS標準形式）、WebP
- **メモリ使用量**:
  - アイドル時: 50MB以下
  - 画像処理時: 150MB以下
  - ピーク時: 200MB以下（メモリ警告が発生しないこと）
- **スループット**:
  - 同時処理数: 1（同時に複数の変換は実行しない）
  - 連続変換間隔: 最低1秒の間隔を推奨（APIレート制限保護）

### 可用性

- **SLA**: 画像変換API利用時は外部サービス（OpenAI等）のSLAに依存
  - 目標稼働率: 99.5%（外部API依存）
  - アプリ自体のクラッシュ率: 0.1%未満
- **オフライン対応**:
  - オフライン時は明確でユーザーフレンドリーなエラーメッセージを表示
  - ネットワーク復帰時の自動リトライは行わない（ユーザーが手動で実行）
  - 過去の変換結果は表示しない（履歴機能は初期バージョンで未実装）
- **リトライ**:
  - 一時的なネットワークエラー時は自動リトライ（最大3回、指数バックオフ）
  - リトライ間隔: 1秒、3秒、5秒
  - リトライ実行中はユーザーにインジケーターで通知（例: 「再接続中... (2/3)」）
  - API側のレート制限エラー（429）時は自動リトライしない（手動のみ）
  - タイムアウト（30秒）到達時はリトライを中止
- **エラー回復**:
  - アプリクラッシュ後の再起動時、前回の状態は復元しない
  - 処理中のクラッシュによるゾンビプロセスやメモリリークを防止

### セキュリティ

Constitutionのセキュリティポリシーに準拠し、UI/UXを損なわない範囲で以下の要件を満たす：

- [x] **データ保護**: 画像データは変換処理完了後、端末内の一時キャッシュから即座に削除
- [x] **通信の暗号化**: 外部APIへの通信はHTTPS（TLS 1.2以上）で暗号化
- [x] **ユーザー同意**:
  - 初回起動時に画像データを外部APIに送信することへの同意を取得
  - 同意画面はシンプルで分かりやすい文言を使用
  - 同意しない場合はアプリを使用できない旨を明記
- [x] **機密情報の管理**:
  - APIキー等の機密情報は環境変数またはセキュアストレージで管理
  - ソースコードやログにAPIキーをハードコードしない
  - Git履歴にも機密情報をコミットしない（.gitignore設定を徹底）
- [x] **入力値検証**:
  - 画像ファイルの形式、サイズ、内容を検証
  - 不正なファイルやマルウェアの可能性がある場合は処理を拒否
  - ユーザーへのエラーメッセージは技術詳細を含めない（ログには記録）
- [x] **プライバシー**:
  - 画像データはローカルで一時的にのみ保持
  - 外部APIへの送信時はユーザーが選択した画像のみを送信
  - バックグラウンドでのデータ送信は行わない

### 観測性

- **ログ**:
  - 画像選択イベント（成功/キャンセル、画像サイズ、形式）
  - 画像変換リクエスト（成功/失敗、処理時間、エラーコード）
  - エラー発生時の詳細情報（エラーコード、タイムスタンプ、ユーザー操作フロー、スタックトレース）
  - API呼び出しの結果（レスポンスコード、処理時間、リトライ回数）
  - セキュリティイベント（不正なファイル検出、認証エラー等）
  - パフォーマンスメトリクス（メモリ使用量、CPU使用率）
  - ユーザーアクション（ボタンタップ、画面遷移、共有・コピー操作）
  - **注**: 個人情報（画像の内容、生成されたテキスト、位置情報）はログに記録しない
  - **ログレベル**: ERROR（エラー）、WARN（警告）、INFO（情報）、DEBUG（デバッグ、開発環境のみ）
- **メトリクス**:
  - 画像変換成功率（日次、週次、月次）: 目標 95%以上
  - 平均変換時間（p50, p95, p99）: p95 < 10秒
  - エラー発生率（エラータイプ別、ネットワーク、API、検証エラー等）: 目標 5%未満
  - アプリクラッシュ率: 目標 0.1%未満
  - 各画面の滞在時間（UX改善のため）
  - DAU/MAU（デイリー/マンスリーアクティブユーザー）
  - 機能利用率（コピー、共有、編集機能の使用頻度）
- **トレース**:
  - 画像選択から変換完了までのエンドツーエンド処理時間（各ステップの内訳付き）
  - API呼び出しのレスポンスタイム（ネットワーク遅延、サーバー処理時間の分離）
  - UI操作のレスポンスタイム（タップからフィードバックまで）
  - メモリ使用量の推移（画像読み込み前後、処理中、処理後）
- **アラート**:
  - エラー率が10%を超えた場合（5分間の移動平均）
  - API応答時間がp95で15秒を超えた場合
  - アプリクラッシュ率が1%を超えた場合
  - メモリ使用量が200MBを超えた場合

### ユーザビリティ

- **直感性**: 初めてのユーザーでもチュートリアルなしで基本操作を理解できる
- **フィードバック**: すべての操作に対して200ms以内に視覚的フィードバックを提供
- **エラーメッセージ**:
  - 技術用語を避け、ユーザーフレンドリーな表現を使用
  - エラーの原因と解決方法を明確に提示
  - パニックを引き起こす表現（「エラー」「失敗」等）を最小限に
- **一貫性**: iOS/Androidそれぞれのプラットフォームのデザインガイドラインに準拠

## 9. テストデータ定義

### 画像テストデータ

テストに使用する画像データのカテゴリを定義します。

**正常系テストデータ**:

- 標準的な写真（風景、人物、オブジェクト）: JPEG、PNG、HEIC各形式
- サイズ範囲: 100KB〜10MB
- 解像度範囲: 640x480〜4000x3000ピクセル

**境界値テストデータ**:

- 最小サイズ: 100x100ピクセル、1KB
- 最大サイズ: 10MB（10,485,760バイト）ちょうど
- 最大サイズ+1バイト: 10,485,761バイト（エラー確認用）
- 最小サイズ未満: 99x99ピクセル（エラー確認用）
- 極端に大きい解像度: 10000x10000ピクセル（メモリテスト用）

**異常系テストデータ**:

- 非対応形式: GIF、BMP、TIFF、SVG
- 破損画像ファイル
- 画像に偽装されたテキストファイル
- 空ファイル（0バイト）
- 画像メタデータのみでピクセルデータがないファイル

**特殊ケーステストデータ**:

- 透過PNG（アルファチャネル付き）
- CMYK色空間のJPEG（通常はRGB）
- EXIFデータを含む画像（位置情報、カメラ情報等）
- 回転情報（EXIF Orientation）を含む画像
- モノクロ画像

### API レスポンステストデータ

**正常系レスポンス**:

- 標準的な説明文（100〜500文字）
- 短い説明文（50文字未満）
- 長い説明文（1000〜5000文字）

**境界値レスポンス**:

- 空文字列（エラーハンドリング確認用）
- 極端に長い文字列（10000文字以上）
- 特殊文字を含む文字列（絵文字、記号、制御文字）

**異常系レスポンス**:

- HTTPエラー: 400、401、403、404、429、500、502、503、504
- ネットワークタイムアウト
- 不正なJSONレスポンス
- 必須フィールド欠落のレスポンス
